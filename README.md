# Shahariar Khan Nobel — Academic Website

This folder contains the complete static website. No software installation is required.

## Preview on your computer
Double-click `index.html` to open the site in your browser. Keep every file in this folder together.

## Publish with GitHub Pages
1. Use the public repository `snobelresearch.github.io` under the account `snobelresearch`.
2. Upload the six files in this folder to the top level of the repository, not the ZIP file and not an enclosing folder.
3. Commit the files to `main`.
4. Open Settings → Pages. Set Source to Deploy from a branch, Branch to main, and Folder to /(root). Click Save.
5. Check Settings → Pages or the Actions tab for publication status. The intended address is https://snobelresearch.github.io/.

## Website files
- index.html — page content
- styles.css — typography, colors, and responsive layouts
- site.js — email copying and navigation highlighting
- research-editorial.webp — original editorial illustration
- Shahariar-Khan-Nobel-CV.pdf — supplied CV converted to PDF
- README.md — these instructions

## Updating the site
Edit the relevant file in GitHub, then commit the change. GitHub Pages republishes the site from main. Replacing the PDF with the same filename updates the downloadable CV.

Publication and professional-history content is based on the supplied CV. The developing AI-and-journalism research direction is based on the author's current research discussions and is identified as developing work.
